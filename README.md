# Lifting Diary

A personal workout tracking app built with Next.js. Log your lifting sessions, track exercises by date, and monitor your progress over time.

## Features

- **Dashboard** — View and manage your workouts by date using an interactive date picker
- **Workout Logging** — Add workouts with exercises, sets, reps, and weight
- **Dark Mode** — Automatic light/dark theme based on system preference
- **Authentication** — Secure sign-in via Clerk

## Tech Stack

- [Next.js 16](https://nextjs.org) (App Router) with React 19 and TypeScript
- [Tailwind CSS 4](https://tailwindcss.com) for styling
- [shadcn/ui](https://ui.shadcn.com) component library
- [Drizzle ORM](https://orm.drizzle.team) for database access
- [Clerk](https://clerk.com) for authentication

## Getting Started

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Commands

```bash
npm run dev      # Start dev server
npm run build    # Production build
npm run start    # Start production server
npm run lint     # Run ESLint
```
